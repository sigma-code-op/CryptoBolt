## Cannibalization rules

- Keep `/app.html` as the functional terminal destination. Use `/crypto-trading-terminal.html` as the explanatory SEO landing page.
- Keep `/trade.html` as the interactive paper-trading account. Use `/crypto-paper-trading.html` as the educational landing page.
- Keep `/ai.html` as the live AI workspace. Use `/ai-crypto-research.html` as the explanatory SEO landing page.

## Content gaps for future pages

The current site has no dedicated search landing page for Solana live price, crypto funding rates, liquidation-price calculation, crypto trading fees, price alerts, or portfolio tracking. Create those only when each page can provide genuinely distinct data and copy; otherwise keep them as sections on the existing pillar pages.
